# UX Checklist: Model and Provider Assignment

**Created**: 2026-06-08 | **Feature**: [spec.md](../spec.md)

> Requirements-quality checklist ("Unit Tests for English") for the UX domain of E005. Each item questions whether the spec / plan / research adequately define a UX requirement (states, affordances, messaging, discoverability, edge-state surfacing, meaning) — not implementation behavior or visual styling. Audience: Reviewer (PR).
