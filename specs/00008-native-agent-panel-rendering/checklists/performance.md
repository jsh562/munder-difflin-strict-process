[Clarity, Spec §FR-010, Data-model §C9] <!-- Evaluator: Covered by spec.md §FR-027 (off-screen entries unmounted while their underlying events remain retained — no eviction) + data-model §C9 (view-models derived, retained cost is the event stream) -->

[Completeness, Data-model §C9, Spec §Key Entities] <!-- Evaluator: Covered by data-model §C9 (both view-models derived, NOT persisted) + Relationships (both derive from the one retained event stream; the single shared stream is where retained cost accrues, projections are recomputable) -->
