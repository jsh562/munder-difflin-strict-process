# Research — Provider credential management (E004)

## Plaintext-config secret store (MVP, with precedent)
ADR-0007 accepts plaintext-at-rest for the MVP, explicitly trading at-rest protection for simplicity and cross-platform reliability (no Linux-keyring edge cases). The harness already does exactly this: `src/main/config.ts` persists `slackSigningSecret` / `slackBotToken` in `HarnessConfig` (config.json under `app.getPath('userData')`) with a "Never logged" convention. config.json lives in the OS app-data dir — outside any registered/project repo and outside the hive git — so the "outside any repo" requirement is met by reusing this store. E004 adds one credential per provider, keyed by the E002 provider id. Sources: SAD ADR-0007; src/main/config.ts (Slack-secret precedent).

## Spawn-time key injection seam (reusable for keychain migration)
The key reaches a native agent only at worker spawn: the E003 `utilityProcess` fork (`electronWorkerTransport`) is given the provider's key in the child's environment, which the E006 adapter reads. ADR-0007's load-bearing rule: this injection point must be a single seam, so a later `safeStorage`/OS-keychain backend swaps behind it without changing the worker or the adapters. So E004 exposes `injection(providerId) → env`/credential and wires it into the spawn; the storage backend is hidden behind that seam. Claude agents are unaffected (they use their own login, not an API key from this store). Sources: SAD ADR-0007; E003 contracts/native-worker-interface.md; ADR-0003.

## Non-leakage boundaries (the real security property)
Plaintext at rest is accepted, but a key must NEVER reach three sinks: the single-committer git hive (board/log/registry/agent files), Claude transcripts (`~/.claude`), or the OTel/telemetry output (`src/main/telemetry.ts`, already PII-scrubbed/allowlisted). The worker is a separate process and never touches the hive; the key lives only in config.json + the worker's spawn env; cost/telemetry carries usage fields only, never credentials. A test should assert the key value is absent from hive writes, transcript reads, and emitted telemetry. Sources: SAD ADR-0007; HIVE.md single-committer; src/main/usage.ts/telemetry.ts (PII-free-by-construction).
