# Security Checklist: Cross-Provider Cost Telemetry
**Created**: 2026-06-09 | **Feature**: [spec.md](../spec.md)

Requirements-quality ("unit tests for English") review of the Security/non-leak surface of E007 — secrets never in telemetry, least-attribute emission, content-capture-off, the fail-closed collector allowlist, no-leak via diagnostic/error paths, loopback-only exposure, and the usd=null/parity-warning contract. Each item interrogates whether the secret-handling and non-leak requirements are clear, complete, consistent, measurable, and traceable, and whether the threat surface and its expected handling are well-defined — not whether code or a pentest passes.

- [X] CHK001 Do the requirements state that API keys and other secrets MUST NEVER appear in any emitted telemetry, naming each carrier explicitly (spans, metrics, attributes, AND collector output) rather than a generic "telemetry"?
